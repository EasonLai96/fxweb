# 槓桿交易練習場（網頁版 MVP）

純靜態網頁，可直接掛 GitHub Pages。單人、本機存檔、無後端、無排行榜。
**這是練習遊戲，行情是虛構的，不是真實市場報價。**

## 掛到 GitHub Pages

1. 把這個資料夾的檔案（不含 `server.mjs`、`*.test.mjs`、`sim.smoke.mjs` 也行）推到 GitHub repo。
2. repo → Settings → Pages → Source 選你的分支根目錄（或 `/docs`）。
3. 等它給你 `https://<帳號>.github.io/<repo>/` 網址，手機開即可。

> GitHub Pages 只能放靜態前端。這版沒有後端也不需要後端。
> 之後若要做「可信排行榜」，必須另外部署伺服器（GitHub Pages 做不到）。

## 本機預覽

```sh
cd fxweb
node server.mjs      # http://127.0.0.1:8799
```

## 測試

```sh
node --test          # 引擎單元測試（10 項）
node sim.smoke.mjs   # 整場模擬 + 帳本一致性
```

## 檔案

| 檔案 | 作用 | 要不要上 Pages |
|---|---|---|
| `index.html` `styles.css` | 介面 | 要 |
| `app.mjs` | 前端主程式（渲染、下單、tick 迴圈） | 要 |
| `engine.mjs` | 交易引擎（開平倉、保證金、手續費、損益、強平、穿倉） | 要 |
| `market.mjs` | 虛構行情產生器：K 線、新聞事件（固定種子可重播） | 要 |
| `charts.mjs` | Canvas 圖表：K 線、均線、迷你走勢、淨值曲線 | 要 |
| `store.mjs` | localStorage 存檔 | 要 |
| `server.mjs` | 本機預覽用的 Node server | 不用 |
| `engine.test.mjs` `sim.smoke.mjs` | 測試 | 不用 |

## 規格（本版決定）

- 帳戶幣別 USD，起始 $10,000。
- 六個貨幣對：EUR/USD、GBP/USD、USD/JPY、USD/CHF、AUD/USD、USD/CAD。USD/XXX 的損益以現價換回 USD。
- 槓桿 1~10 倍（滑桿，整數）。手續費 = `名目 × (0.005% + 槓桿 × 0.0005%)`。
- 虧損達保證金 60% 警告、80% 強制平倉。
- 跳空可穿倉 → 允許淨值變負，但**凍結新開倉**，需平倉或重置才能繼續（穿倉方案 A）。
- 損益公式 `pnl = 方向 × (現價 − 進場價) × (名目 / 進場價)`（已單元驗算）。
- 每 1.5 秒一根 K 線，含 MA10/MA30、新聞標記、進場價與強平價虛線。
- 新聞快訊：約 24% 新聞會出現與標題相反的走勢。

## 這版「刻意不做」的

- 借貸、每日挑戰、歷史回放、經典戰役、成就。
- 可信排行榜、跨裝置同步（需要後端）。
- 真實即時報價（Frankfurter 是日線，第二階段才接）。

本機存檔可被任意修改，UI 已標明不是可信成績。

## 帳號與雲端存檔

右上角可以註冊 / 登入（帳號密碼）。登入後存檔同步到雲端，換裝置可以接著玩；兩台裝置進度不同時會讓你選要用哪一份。後端是 Cloudflare Workers + D1，程式在 `server/`，說明見 `server/README.md`。沒有忘記密碼功能。存檔內容由瀏覽器產生，不是可信成績。
