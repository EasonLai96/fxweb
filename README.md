# 槓桿交易練習場

靜態前端部署於 GitHub Pages，帳號與可信帳戶計算使用 Cloudflare Workers + D1。
**練習遊戲・虛構行情，非真實報價，非投資建議。**

## 兩種模式

- 訪客：本機計算與 localStorage 存檔，可暫停，不計可信成績。
- 登入：伺服器產生行情、定價、核算餘額、交易與強平。修改網頁或本機存檔不會改到伺服器帳戶；換裝置讀同一帳戶。
- 起始 $10,000；14 個商品（6 組外匯、4 檔 ETF、4 種虛擬幣）；槓桿可選 1–10 倍、50 倍、100 倍（11–49 與 51–99 倍不可選）；保證金至少 $10，最多 20 筆持倉。50×／100× 高風險：理論反向約 1.6%／0.8% 即達強平門檻，跳空可能穿倉。
- 每1.5秒一根K線；虧損達保證金80%強平。離線行情依經過時間補算，每次最多600根，完全追平前不可交易。離線不免除虧損或強平。
- 登入玩家共用一條虛構行情：同一時間、同一貨幣對價格一致；訪客仍使用個人本機練習行情。登入新持倉滿 7 天按到期 tick 價自動平倉；離線期間仍逐根結算，可能需多次請求追平。
- 舊帳戶尚有舊版個人行情持倉時沿用原行情並暫停新開倉；全部平倉或強平後保留現金與成就切換共同行情，並非直接換價。舊持倉不追溯 7 天限制。
- 本季排行榜按從 $10,000 全新回合開始的帳戶權益報酬率排序，包含浮動損益。參賽需登入後自選公開暱稱與主動加入；同季退出或重置後不可重入，下一季重新加入。榜單只是玩家最近提交的分數快照，**不保證每位離線玩家都已即時結算**。無真人驗證，一人多帳號等無法完全阻止。

## 止損／止盈、好友房、安裝到桌面

- **止損／止盈**：開倉時可選填止損價與止盈價，持倉中也能隨時修改或取消（「止損盈」按鈕）。每根 K 線先檢查強平、再檢查止損止盈；以中間價判斷是否觸及，按實際成交價（含價差／滑價）平倉，可能因跳空成交在比設定更差的價格。做多止損須低於現價、止盈須高於現價，做空相反。圖表以紅／綠虛線標示，訪客模式同樣適用。止損止盈平倉不算強平。
- **好友房**：登入玩家可建立私人排行榜，取得 6 碼邀請碼（或分享 `?room=邀請碼` 連結）讓朋友加入。房內只顯示各自在房內選的暱稱，不顯示登入帳號；成績為淨資產（權益－借款）報酬率，在玩家帳戶被伺服器存檔時更新。每人最多 5 房、每房最多 50 人；房主退出即解散房間；刪除帳號會一併移除房間與成員資格。
- **安裝到桌面（PWA）**：手機瀏覽器選「加到主畫面」即可像 App 一樣全螢幕開啟。Service worker 只快取同網域靜態檔且一律網路優先，API 永不快取，不會卡在舊版。
- 登入玩家行情每 3 秒同步一次（一次帶回 2 根 K 線），在線心跳每 60 秒一次，以節省免費額度；行情本身仍是每 1.5 秒一根。

## 成就、統計、分享與新手指導

- 成就由伺服器依交易事件解鎖，跨重置保留；訪客不取得可信成就。
- 統計分本回合與累積資料；已實現淨損益扣除已平倉對應的開倉費，開倉費總額也包括尚未平倉部位，不可再次重複相減。
- 舊帳戶從此功能啟用後開始記錄，不憑截斷的舊紀錄猜測完整歷史。
- 分享卡可下載 PNG，支援的手機可直接系統分享；薄荷色版面包含真實已存的淨值樣本曲線與指向網站的 QR 碼。預設不顯示帳號，可自行選擇公開；圖片只是當時快照，不是不可偽造的成績憑證。
- 分享頭像可選擇 JPG、PNG 或 WebP（上限 5 MB）。圖片在瀏覽器裁切重繪成 256×256 後只存在目前裝置、依帳號分開；不傳到伺服器，換裝置需重新選。可隨時移除。
- 新手指導含互動槓桿示例與風險練習，不會替使用者下單；略過後仍可隨時重看。

## 忘記密碼

註冊時保存一次性顯示的救援碼。登入頁「忘記密碼」可用帳號、救援碼設定新密碼。成功後舊碼失效、其他裝置登出，必須保存新碼。
舊帳號請登入後按「產生新救援碼」，需目前密碼。密碼和救援碼都遺失時無法自行恢復。

## 舊版升級

舊瀏覽器上傳資料不能證明真實交易，因此不匯入新版可信帳戶；新版從$10,000開始。D1舊saves資料保留但停用API，本機訪客存檔不刪除。

## 安全範圍

防止直接竄改餘額、成交價、損益及瀏覽器快轉行情。未來行情使用伺服器256bit秘密與HMAC-SHA256，秘密不回傳客戶端。救援碼只存雜湊；重設採原子消耗。交易使用版本鎖與有限128筆requestId去重。
這不是「絕對不能作弊」保證：帳號分享、自動交易腳本、多帳戶操作和所有未知漏洞並不因此消失。CORS僅限制瀏覽器跨站讀取，並非API存取防火牆。

## 開發

前端無建置步驟，用靜態HTTP伺服器開啟；API網址在config.mjs。
後端部署與測試參見server/README.md。執行測試需要Node 22的node:sqlite。

## 面板與交易實驗室（本輪更新）

- 桌機商品欄有界捲動，手機提供行情／下單／持倉／資金／實驗室導覽，支援日夜、鍵盤焦點及減少動畫。
- 訪客帳戶與完整行情以 version 2 同份原子存檔，重整續接原報價。舊存檔若沒有行情，不會靜默換價搬倉：先暫停，提供原始備份下載，再經明確同意重新開始；第一份原始備份不覆寫。瀏覽器阻擋／清除儲存仍可能造成資料遺失。
- 交易回執在登入帳號下獨立保留，送出前儲存完整操作與 requestId，不存 token／密碼。未知結果會鎖定新遊戲操作；使用者可查詢回執，或核對最新帳戶後明確解除鎖定。伺服器僅保留最近 128 筆，unknown 不代表未成交，因此不會盲目重送。Web Locks 可用時阻止同裝置跨分頁同時送單；無此能力時只有持久化檢查，不保證跨分頁原子隔離。
- 風險預算以淨資產比例、方向、止損與預估持有時數推算保證金。登入模式估算壓力價差、滑價與融資費；不含小金庫利息，也不保證止損成交或損失上限。再跳空 1% 情境僅作壓力示範。按「套用」只填表，不下單。
- 學習日誌只存在目前裝置，依帳號與模式隔離，最多 200 筆，可匯出 JSON。僅記錄本頁觀察到的持倉及結算；浮盈虧樣本不是完整離線 MFE/MAE，且部分平倉前後非同等倉位，不能當標準化績效。成本不完整不冒稱淨收益。
- 部分平倉比例針對「目前剩餘部位」，按比例分攤保證金、名目、已付開倉費及融資費，剩餘 id／開倉時間／止損止盈保留。已付成本不退不重扣；每次部分平倉計一次結算統計。
- 新版統計與盈利成就扣已關閉部分對應融資成本。舊累積統計無法可靠重建，以 carryAccountingSince／carryHistoryComplete 揭露，不回溯猜測或撤銷既有成就。小金庫借款利息與倉位融資費不同，不納入單筆交易淨損益。
- 產生救援碼／刪帳改用遮蔽密碼的確認對話框；註冊登入於密碼雜湊前原子預留節流額度。
